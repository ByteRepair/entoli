description: Group the current changes into commits and write their messages

Commit what has changed in this workspace.

$ARGUMENTS

Read the diff first. Group the changes into commits that each stand on their
own, rather than one commit per file or one commit for everything. Write a
subject line under 72 characters saying what changed, and add a body only where
the reason is not visible in the diff.

Do not push. Report what you committed and what you left unstaged.
